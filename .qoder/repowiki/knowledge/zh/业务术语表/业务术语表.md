### 多页面作品集
- 定义：本项目的中文名称，指代基于 Next.js 构建的个人作品集网站模板，包含博客、项目展示和关于页等多个独立页面，采用配置驱动的内容管理模式。
- 别名：Multiple Page Portfolio、multiplepage-portfolio

### zzming's Portfolio
- 定义：站点实际展示的名称，位于 `src/config/content.ts` 的 `siteConfig.name` 字段，是该项目对外展示的站点标题。
- 别名：zzming 作品集

### generate-posts
- 定义：构建期脚本命令 `npm run generate-posts`，负责扫描 `src/posts/*.md` Markdown 源文件，解析 frontmatter 并使用 marked 生成 HTML，最终产出 `src/config/posts.ts` 配置文件和 `generated/posts/*.html` 静态内容，供 Next.js 构建时读取。
- 别名：posts 生成脚本

### static export
- 定义：Next.js 构建模式，通过 `output: 'export'` 将应用编译为纯静态 HTML/CSS/JS 文件，不依赖 Node.js 运行时，可直接部署到 GitHub Pages、Cloudflare Pages、EdgeOne Pages 等静态托管服务。
- 别名：静态导出、SSG export

### dark/light mode
- 定义：全站主题切换能力，通过 next-themes 库配合 Tailwind CSS 的 `darkMode: 'class'` 实现，默认主题为 dark，支持跟随系统偏好。所有样式类名通过 `dark:` 前缀区分明暗主题变体。
- 别名：深色/浅色模式、主题切换

### PostCard pattern
- 定义：文章卡片组件支持的四种背景纹理图案：`dots`（点阵）、`grid`（网格）、`waves`（波浪）、`circles`（圆形），通过 PostCard 组件的 `pattern` 属性选择，每种图案在明暗主题下均有对应配色。
- 别名：卡片背景图案
