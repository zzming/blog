本仓库为单包 Next.js 16 项目，采用 `output: 'export'` + `trailingSlash: true` + `images.unoptimized: true` 将站点导出为纯静态 HTML/CSS/JS，可直接托管于任意静态服务器。
- 入口与路由：由 Next.js 约定式文件路由驱动（`src/pages`、`src/app`），页面与组件通过 Tailwind content 路径扫描自动包含。
- 样式层：Tailwind CSS 3 配合 `@tailwindcss/typography` 插件，并通过 `darkMode: 'class'` 实现手动主题切换；`next-themes` 在运行时注入 theme class。
- 内容层：Markdown 博文经 `gray-matter` 解析 frontmatter，再由 `react-markdown` + `remark-gfm` + `react-syntax-highlighter` 渲染，`scripts/generate-posts.js` 提供预生成脚本。
- 类型系统：`tsconfig.json` 启用 strict 模式、`moduleResolution: bundler`、`jsx: react-jsx`，并通过 `paths.@/* → ./src/*` 统一绝对导入；`tsconfig.scripts.json` 单独服务于 Node 侧脚本（如 generate-posts）。
- 依赖方向：根配置仅声明依赖，业务逻辑下沉至 `src/` 下的 pages/app/components 等子目录（不在本 leaf 范围内）。
